# Белград: первые 7 дней

Одностраничный mobile-first гид на русском языке для новичков в Белграде. Статический сайт: сборщик, внешние шрифты и платные сервисы не нужны.

## Локальный просмотр

Из корня рабочего проекта запусти:

```sh
python3 -m http.server 4173 --directory output/belgrade-first-week
```

Из корня репозитория запусти:

```sh
python3 -m http.server 4173
```

Открой `http://127.0.0.1:4173`.

## Разделы

1. SIM-карты: выбор на первый месяц, два альтернативных сценария и регистрация номера.
2. Регистрация адреса в течение 24 часов и подтверждение проживания.
3. Оптовый список овощных цен и конфликт официальных часов рынков.
4. Тарифный статус городского транспорта.
5. Интерактивный расчёт 30-го дня безвизового пребывания для обычного паспорта РФ.
6. Приглашение в разговорный клуб через Telegram.

## Дизайн и формулировки

Тёплый бумажный фон, тёмно-зелёные блоки, коралловые акценты и простые карточки. Русский текст короткий и бытовой; в каждой теме решение или оговорка стоит рядом с действием. Цены, условия, расхождения и даты проверки показаны прямо, без декоративных иллюстраций и внешних зависимостей.

## Источники

Ссылки на официальные страницы операторов, сербские законы, МВД, МИД, туристическую организацию Белграда и публичные рынки встроены в соответствующие разделы. Факты проверены 19 октября 2026 года; если исходная страница не публикует дату обновления или единицу измерения, это отмечено в интерфейсе.
